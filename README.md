# 📱 4PetsCare

Aplicación móvil desarrollada con **React Native** usando **Expo Go**, cuyo propósito es **ayudar a mantener el cuidado y el bienestar de tus mascotas**.

---

## Características

-  Interfaz desarrollada con React Native  
-  Compatible con Android e iOS mediante Expo Go  
-  Recarga en caliente (Hot Reload)  
-  Arquitectura modular y escalable  
-  Diseño responsivo  

---

## Tecnologías utilizadas

- React Native  
- Expo  
- JavaScript 
- Node.js  
- npm o yarn  

---

##  Instalación

Sigue estos pasos para ejecutar el proyecto localmente:

### 1. Clona el repositorio

```bash
git clone https://github.com/YondaimeMex/4PetsCare.git
````

### 2. Entra al directorio del repositorio

```bash
cd nombre-del-repositorio
````
### 3. Instala las dependencias

Con npm:

````bash
npm install
````
o con yarn:

````bash
yarn install
````

## ▶ Ejecución del proyecto

### 1. Inicia el servidor de desarrollo

````bash
npx expo start
````
### 2. Instala Expo Go en tu dispositivo móvil

````
Disponible en Play Store o App Store
````

### 3. Abre la aplicación

````
Escanea el código QR de tu proyecto
````
